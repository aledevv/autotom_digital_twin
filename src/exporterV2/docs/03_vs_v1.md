# ExporterV2 vs ExporterV1

## Key Differences

| Aspect | V1 | V2 |
|--------|----|----|
| **Architecture** | Monolithic | Modular (core/adapters/profiles) |
| **Reusability** | CSV-specific | Generic (any plant) |
| **Lateral branches** | ❌ Not supported | ✅ Supported with collision check |
| **Leaf filtering** | Simple | Profile-driven (opposite pairs, etc.) |
| **Configurability** | Hardcoded | Profile-based |
| **Testing** | Manual | Automated test suite |
| **Phyllotaxis** | ❌ No | ✅ Optional fallback |
| **Collision detection** | ❌ No | ✅ Geometric checks |

---

## Architecture Comparison

### V1 (Monolithic)
```
exporterV1/
├── main.py           # Everything in one file
└── graph_export.py   # CSV parsing + USD gen mixed
```

### V2 (Modular)
```
exporterV2/
├── core/             # Generic (reusable)
├── adapters/         # CSV-specific
├── profiles/         # Cultivar-specific
└── tests/            # Automated tests
```

## Migration Path

### From V1 to V2

**No migration needed!** V2 is backward compatible:

```bash
# V1 command (still works)
./run_main.sh --day 100

# V2 command (new)
./run_mainV2.sh --day 100
```

**Output identical** for trunk + trunk leaves (when no laterals present).

---

## When to Use V1 vs V2

### Use V1 if:
- Simple trunk + leaves only
- No lateral branches needed
- Prototyping/quick tests

### Use V2 if:
- Full plant structure (trunk + laterals + leaves)
- Need configurability (profiles)
- Testing collision scenarios
- Reusable for multiple cultivars
- **Production use** ✅
