# Exporter V2 vs V1

Exporter V1 remains a legacy static/kinematic baseline. Exporter V2 is the active pipeline for physics-enabled tomato plants in Isaac Sim.

| Area | V1 | V2 |
| --- | --- | --- |
| Architecture | monolithic exporter | modular core/adapters/profiles |
| CSV parsing | static plant reconstruction | full branch, leaf, truss, and tomato hierarchy |
| Physics | static or limited rigid setup | articulated PhysX links with D6/Fixed joints |
| Leaves | basic/static geometry | petiole, rachis, petiolules, and blade hierarchy |
| Trusses | absent or static baseline | CSV-derived rachis, pedicels, tomatoes, and detachment |
| Tomatoes | visual fruit | rigid terminal bodies with breakable FixedJoints |
| Materials | organ colors for visual inspection | organ colors plus tomato maturity/ripening colors |
| Optimization | none | joint-budget optimizer and visual validation assets |
| Runtime | simple USD export | Isaac Sim runtime settings, GPU dynamics, collision filters |

## When to Use Each

Use V2 for current work, Isaac Sim interaction, truss experiments, paper figures, and final reporting. Use V1 only when a historical static baseline is needed.

## Current V2-Only Features

- CSV-derived lateral branches with geometric anti-collision checks
- compound leaves with configurable generation switches
- truss rachis, pedicels, tomato sizing, maturity colors, and detachment
- colored stems, leaves, trusses, and tomato maturity states for videos and figures
- `/World/TerminalBodies` for detachable rigid tomatoes
- joint-budget optimization techniques and before/after demos
- test split between pure pytest, Isaac/PhysX tests, and manual visual demos
