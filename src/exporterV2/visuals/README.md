# Mesh generators

Every mesh in the exported plant is generated by code. This page is the map:
where each generator lives and which `config/visuals.yaml` switch drives it.
Physics never depends on these meshes; colliders are simple capsules built in
`core/usd/`.

| Part of the plant | Generator | Code | Switches in `config/visuals.yaml` |
| --- | --- | --- | --- |
| Stems, side shoots, petioles, leaf rachis, truss rachis, pedicels | Organic swept tube, one mesh per rigid link: taper, smooth radius changes, root flare, junction bulge | `core/skinning/visual_segmented.py` (`author_segmented_visual_axis`), shape maths in `core/skinning/mesh.py` (`_visual_radius`, `build_axis_tube_data`), defaults in `core/skinning/model.py` (`VisualProfile`) | `quality`, `stems.junction_bulge` |
| Decorative twig at a branch tip that ends in a leaf | Small curved shoot plus a tiny leaf | `core/skinning/terminal_fork.py` (`author_terminal_visual_forks`) | `stems.terminal_forks` |
| Leaflet stalk (petiolule) | Same organic tube as the stems | `visuals/leaves.py` (`author_leaf_visuals`) | `pose` |
| Leaflet blade, `simple` | Procedural blade: width profile, fold, arch, gravity sag | `core/skinning/leaf_blade.py` (`author_leaf_blade`) | `leaves.generator: simple` |
| Leaflet blade, `real_leaves` / `real_leaves_i3` | Shapes sampled from scanned tomato leaflets by the `external/real_leaves` submodule, run in a separate Python worker | `leaf_shapes/` (client, worker, `config.py`), settings in `profiles/leaf_shape.yaml` | `leaves.generator`, `leaves.seed` |
| Truss rachis colour | Truss material on the organic mesh | `visuals/trusses.py` | none |
| Pedicel curve | Curved "gravity elbow" tube replacing the straight pedicel mesh | `core/usd/pedicel_geometry.py` (`create_gravity_elbow_mesh`), applied by `visuals/trusses.py` | `pedicels.gravity_curve` |
| Tomato | Sphere coloured by ripeness | `core/usd/terminal_bodies.py` (`build_terminal_bodies`) | `fruits.generator` (only `sphere`) |
| Materials | Shared PBR materials for leaves, stems, truss and 8 ripeness buckets for tomatoes | `core/usd/materials.py` | none |

The orchestration (which generator runs for which part) is in
`exporter.py`; the per-link visual settings come from `skeleton_branches.py`
(`_visual_profile`).

## Changing a look

- **Thicker or thinner junctions, taper, ring density:** edit the defaults of
  `VisualProfile` in `core/skinning/model.py`; `quality: performance` already
  lowers the ring and radial counts.
- **Different leaflet shape:** switch `leaves.generator`, or change
  `core/skinning/leaf_blade.py` for the `simple` blade.
- **Different tomato colour:** `_tomato_color` in `core/usd/materials.py`.
- **A new fruit shape:** add a value to `fruits.generator` in `config.py`
  (`_VISUALS_CHOICES`) and branch on it where `terminal_bodies.py` authors the
  sphere (`create_sphere_rigid_body` in `core/usd/geometry.py`).

After a change, run `./run_mainV2.sh --generate-only` and open
`output/plant.usda`, then the visual tests:

```bash
uv run pytest -q src/exporterV2/tests/test_real_leaf_shapes.py src/exporterV2/core/skinning/tests
```
